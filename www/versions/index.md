# Version history

> One line per push to dev: the repository's version, the kit release it serves, and what changed.

*Source: <https://api.storyboards.sgit.ai/versions/index.html>.*

---

| Version | Date | Kit | What changed, and why |
|---|---|---|---|
| v0.2.1 | 2026-10-20 | [v0.1.0](../releases/v0.1.0.html) | Two findings from the Lab recorded in REALITY.md for the next kit release, nothing in the kit changed: play() does not start the stroke draw-in in Chromium 141 (the .sb-panel.play path[pathLength] rule is not restyled on the class change; the scrolly experiment works round it with an inline stroke-dasharray), and play() has no promise or event for when an arrival ends. Also asked for by the experiments: the bubble, caption, setting, props and face as exported functions, a walk pose, data-who on actors and bubbles. The kit is unchanged: release v0.1.0. |
| v0.2.0 | 2026-10-20 | [v0.1.0](../releases/v0.1.0.html) | api.storyboards.sgit.ai becomes the developer site: guides (write a storyboard, write a prop pack, render in a build, pin a release), the reference with a live gallery of every kind, setting, prop, pose and mood, the graph format, how the kit works inside, every patch against the upstream files as a diff, a page per release, tests, CI, the release process, and a documentation sidebar. And ABP-SB-001, code immutability: the behaviour policy in riskmandate.ai's shape, its compiled half in JSON, a Claude Code hook that denies any change to a published release folder and asks before any change to its own controls, a git pre-commit hook, and tests/test_policy.py. The kit is unchanged: release v0.1.0. A top-level Behaviour policy page (/abp/), generated from policies/abp.json: the agents, the layers of control, the grant, the mandate, ten rules with their barriers and enforcement, where each maps to, and the gaps. New checks for rules that were prose: the test harness fails any request to a third-party host (ABP-SB-009), and CI refuses an edit to a brief already on dev (ABP-SB-006). |
| v0.1.1 | 2026-10-20 | [v0.1.0](../releases/v0.1.0.html) | CI no longer asks a branch to bump the version when its commit is already on dev (a branch pushed alongside dev failed the check with nothing new in it). The kit is unchanged: release v0.1.0. |
| v0.1.0 | 2026-10-20 | [v0.1.0](../releases/v0.1.0.html) | The first release. The kit gen-z-developers.sgit.ai and pki.sgit.ai each carried a copy of is served once, from /v0/v0.1/v0.1.0/, never to change: the drawing (four marked patches: prop packs, a per-site preferences key, the vocabulary and wire(), an embed's start view), pki.sgit.ai's props as the security pack, Rough.js and the two fonts vendored, and three new files: formats.js (validate, markdown, semantic graph), export.js (SVG, animated SVG, PNG, JPEG, contact sheet) and embed.js (<sg-storyboard>). Each file's SHA-256 and SRI string in the manifest; tools/release.py cuts and checks it; tests in Node and three browsers. |
