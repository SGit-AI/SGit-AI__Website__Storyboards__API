Release v0.1.0

Release v0.1.0 of the kit: every file, its hash, where it came from and what changed.

Published at https://api.storyboards.sgit.ai/v0/v0.1/v0.1.0/ on 2026-10-20: 13 files, 233,785 bytes. manifest.json. This folder is immutable: these bytes never change at this path.

The first release. The kit gen-z-developers.sgit.ai and pki.sgit.ai each carried a copy of is served once, from /v0/v0.1/v0.1.0/, never to change: the drawing (four marked patches: prop packs, a per-site preferences key, the vocabulary and wire(), an embed's start view), pki.sgit.ai's props as the security pack, Rough.js and the two fonts vendored, and three new files: formats.js (validate, markdown, semantic graph), export.js (SVG, animated SVG, PNG, JPEG, contact sheet) and embed.js (<sg-storyboard>). Each file's SHA-256 and SRI string in the manifest; tools/release.py cuts and checks it; tests in Node and three browsers.
