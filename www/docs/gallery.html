The gallery

Every kind, setting, prop, pose and mood of release v0.1.0, drawn live by it.

Every kind, setting and prop that release v0.1.0 knows, in one storyboard of 17 panels, drawn in your browser by v0/v0.1/v0.1.0/storyboard.js now. The storyboard is generated by site/gallery.py from the release's own vocabulary and validated by its own formats.js, so a prop added in a release appears here without anyone drawing a panel for it. Switch to Grid to see them all at once; the script view lists every field used.

Every pose and every mood

The model sheet: each specimen character in each of the moods and poses, the way animators check a character is on model.

The data

The specimen as JSON is specimen.bundle.json; as a script, gallery.md.
