The storyboard kit

The code that draws every storyboard on storyboards.sgit.ai, served so any page can use it: one script tag, pinned to a folder that never changes.

A storyboard here is data: a JSON file naming who is in each panel, their pose and mood, what they say, the evidence and its source, and a cast file saying what each character looks like. This site serves the code that draws them, as sketchy SVG panels with Rough.js, in the reader's browser. storyboards.sgit.ai is where the storyboards live; this is what draws them, there and anywhere else.

Two lines

<script src="https://api.storyboards.sgit.ai/v0/v0.1/v0.1.0/embed.js" defer></script>
<sg-storyboard src="https://storyboards.sgit.ai/pki/the-first-key/bundle.json"></sg-storyboard>

Above: panel 4 of pki.sgit.ai's The first key, drawn now, by this release, from a bundle. Click it to play.

One rule: the path is the version

The current release is v0.1.0, at https://api.storyboards.sgit.ai/v0/v0.1/v0.1.0/. Nothing at that path will ever change: a fix is a new folder, and this one stays. Every file in it is listed below with its SHA-256 and the integrity string a browser checks; every release has its own manifest. There is no latest path, on purpose: a page moves to a new release by changing one line. Versioning has the whole rule and the tools that enforce it.
